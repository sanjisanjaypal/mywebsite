Site editor

Edit text and images on sanjaypal.online. Changes are saved to your GitHub repository, and the live site updates about a minute later.

Your GitHub username, a slash, then the repository name.

Only sent to GitHub. Never put this key in a page or share it.

How do I get a GitHub key?
  1. On github.com, click your photo (top right), then Settings.
  2. At the bottom of the left menu, click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token. Name it "Site editor" and pick an expiry (for example 1 year).
  4. Under Repository access, choose Only select repositories and pick your site's repository.
  5. Under Permissions, open Repository permissions and set Contents to Read and write.
  6. Click Generate token and copy it (it starts with github_pat_). Paste it above.
